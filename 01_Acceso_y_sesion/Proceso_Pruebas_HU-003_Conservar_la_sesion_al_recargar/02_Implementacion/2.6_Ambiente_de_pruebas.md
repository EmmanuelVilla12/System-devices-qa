# 2.6 Ambiente de pruebas · HU-003

**Fase:** Implementación
[Volver al flujo](../00_Flujo_metodologico.md)

## Versión o recurso previsto

| Elemento | Valor previsto |
|---|---|
| Aplicación | Device Systems, instancia de ensayo separada de desarrollo y producción |
| Versión del producto | Por confirmar: se anota la versión desplegada cuando HU-003 entre a ensayo |
| Dirección de la aplicación | Por confirmar por el equipo de desarrollo (no se inventa una URL) |
| Datos | Punto de control de [2.3 Datos](2.3_Datos_de_prueba.md) |

## Características

| Característica | Aplicación a HU-003 |
|---|---|
| Separado de desarrollo y producción | Instancia de ensayo de Device Systems. |
| Vigencia de sesión conocida | Duración o mecanismo de caducidad acordado en PA-01. |

## Roles y cuentas necesarios

| Rol / cuenta | Para qué se usa |
|---|---|
| Usuario `sesion.usuario` | Identidad, vigencia, caducidad |
| Soporte `sesion.soporte` | Permisos del rol, invalidez |
| Administrador del ambiente | Punto de control; vigencia corta si se acuerda |

## Restricciones

- Los desarrolladores no tienen permisos de modificación en el ambiente de ensayo; el administrador del ambiente lo gestiona.
- Cada despliegue en ensayo tiene versión identificada (control de versiones).
- **Nunca** se usan datos reales ni el ambiente de producción.

## Dependencias del ambiente

HU-002 (ingreso), HU-004 (Perfil y caducidad) y HU-006 (cierre por invalidez) del Grupo 1, desplegadas en la misma versión. HU-008 (otro grupo) para Acceso denegado en ACC-REC-003.

## Procedimientos de gestión

| Procedimiento | Cómo se aplica |
|---|---|
| Preparación de datos auditable | Punto de control con las dos cuentas. |
| Caducidad | Mecanismo acordado en PA-01. |
| Invalidez | Mecanismo acordado en PA-02. |

## Lista de verificación del entorno (se usa en 3.1)

| N.º | Verificación | Cumple |
|---:|---|:-:|
| 1 | La aplicación de ensayo responde con la versión esperada | ☐ |
| 2 | Las dos cuentas del punto de control inician sesión | ☐ |

| 4 | Mecanismos de PA-01 y PA-02 acordados | ☐ |

| Función restringida (PA-04) | ACC-REC-003 |
| Perfil con caducidad (HU-004) | ACC-REC-004, 005 |
