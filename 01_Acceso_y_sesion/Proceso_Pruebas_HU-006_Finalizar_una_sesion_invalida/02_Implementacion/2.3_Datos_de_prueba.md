# 2.3 Datos de prueba · HU-006

**Fase:** Implementación
[Volver al flujo](../00_Flujo_metodológico.md) · [Versión CSV](2.3_Datos_de_prueba.csv)

Los datos reemplazan expresiones como «un correo válido» por valores concretos, para que cualquier persona pueda repetir la prueba. Todos son **ficticios** y fueron creados por el Grupo 1 para este banco: el dominio `dsqa.test` usa el sufijo `.test`, reservado para pruebas, y no corresponde a buzones reales. No se usan datos de personas reales, del Excel del grupo ni de la plantilla de ejemplo.

## Datos base del ambiente (punto de control)

Antes de cada corrida el administrador del ambiente restaura la base a este estado. Así los correos de los casos vuelven a estar libres y el resultado se puede repetir.

## Valores especiales

| Código | Valor | Longitud | Observación |
|---|---|---|---|
| NOM-50 | `Luis Alberto García Marín` | 50 | Nombre justo en el límite superior |
| NOM-51 | `Luis Alberto García Marín H` | 51 | Nombre justo un carácter por encima del límite (lleva tilde en `García`) |
| PWD-72 | `TecnOcL2024Km9kkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkk` | 72 | Contraseña con mayúscula, minúscula y número; justo en el límite |
| PWD-73 | `TecnOcL2024Km9kkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkk` | 73 | Contraseña 73 caracteres (uno más que el límite) |

Nombres de 50 y 51 incluyen tilde (`García`) para comprobar que el límite se cuenta en caracteres (PA-06). PWD-72 y PWD-73 = `TecnOcL2024Km9` + 63 o 64 letras `k`. `␠` representa un espacio.
