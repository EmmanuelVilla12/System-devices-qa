# 2.7 Revisión por pares del banco · HU-006

**Fase:** Implementación
[Volver al flujo](../00_Flujo_metodológico.md)

Una persona **ajena al autor** revisa el banco **antes de ejecutar**. Para esta evidencia la revisión la hace el **Grupo 5** sobre la PR de la rama `qa/hu-006`. La revisión no reemplaza la ejecución: confirma que los artefactos se entienden y se pueden repetir. Revisar un script no es ejecutarlo.

| Campo | Valor |
|---|---|

| Cobertura | ¿Cada CA tiene al menos un escenario y cada escenario al menos un caso? | | |
| Sin invención | ¿Los casos evitan URL, códigos de respuesta o textos de error que la ficha no define? | | |

| Repetible | ¿Precondiciones y datos permiten repetirlo igual? | | |
| Verificable | ¿Cada verificación tiene un resultado esperado observable? | | |
| Independiente | ¿El caso no depende de otro, o la dependencia está en la precondición? | | |
| Preciso | ¿Usa valores concretos y no expresiones como «datos válidos»? | | |
| Mantenible | ¿Si cambia un criterio se ubica fácilmente qué actualizar? | | |
| Sin redundancia | ¿Hay casos duplicados u omitidos frente a los escenarios? | | |
| Errores frecuentes | ¿Precondiciones mezcladas con pasos, pasos con varias acciones, resultados subjetivos? | | |
