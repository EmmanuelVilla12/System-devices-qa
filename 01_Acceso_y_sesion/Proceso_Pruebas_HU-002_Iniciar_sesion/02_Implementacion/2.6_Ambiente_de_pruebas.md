# 2.6 Ambiente de pruebas · HU-002

**Fase:** Implementación
[Volver al flujo](../00_Flujo_metodologico.md)

## Versión o recurso previsto

| Elemento | Valor previsto |
|---|---|
| Aplicación | Device Systems, instancia de ensayo separada de desarrollo y producción |
| Versión del producto | Por confirmar: se anota la versión desplegada cuando HU-002 entre a ensayo |
| Dirección de la aplicación | Por confirmar por el equipo de desarrollo (no se inventa una URL) |
| Datos | Punto de control de [2.3 Datos](2.3_Datos_de_prueba.md) |

## Características

| Característica | Aplicación a HU-002 |
|---|---|
| Separado de desarrollo y producción | Instancia de ensayo de Device Systems. |
| Configuración como producción | Mismo límite de 5 ingresos por minuto. |
| Uso exclusivo durante la corrida | Nadie más inicia sesión desde el mismo origen. |

## Roles y cuentas necesarios

| Rol / cuenta | Para qué se usa |
|---|---|
| Usuario `ingreso.usuario` | Ingreso básico, destino, rechazos |
| Administrador `ingreso.admin` | Rol administrador; teclado |
| Soporte `ingreso.soporte` | Inspección de la contraseña |
| Cuenta inactiva | CA-HU-002-04 |
| Cuenta `limite.ingreso` | Límite por minuto |
| Administrador del ambiente | Punto de control y accesos de lectura |

## Restricciones

- Los desarrolladores no tienen permisos de modificación en el ambiente de ensayo; el administrador del ambiente lo gestiona.
- Cada despliegue en ensayo tiene versión identificada (control de versiones).
- **Nunca** se usan datos reales ni el ambiente de producción.

## Dependencias del ambiente

HU-004 Perfil y HU-005 Cerrar sesión (Grupo 1) desplegadas en la misma versión como apoyo de verificación. HU-008 (otro grupo) para Acceso denegado en ACC-ING-010. HU-028 (otro grupo) para la comunicación de errores.

## Procedimientos de gestión

| Procedimiento | Cómo se aplica |
|---|---|
| Preparación de datos auditable | Punto de control con las cinco cuentas; se restaura antes de cada corrida. |
| Accesos | Lectura de base y registros del servicio (PA-05). |
| Herramientas | Panel de red, cronómetro, NVDA, emulación, capturas. |

## Lista de verificación del entorno (se usa en 3.1)

| N.º | Verificación | Cumple |
|---:|---|:-:|
| 1 | La aplicación de ensayo responde con la versión esperada | ☐ |
| 2 | Las cinco cuentas del punto de control existen con su estado | ☐ |
| 3 | Perfil (HU-004) y Cerrar sesión (HU-005) están disponibles | ☐ |
| 4 | Hay lectura de base y registros | ☐ |
| 5 | PA-04 respondida (función restringida) | ☐ |
| 6 | Navegador, emulación y lector disponibles | ☐ |

## Qué impediría ejecutar

| Si falta… | Casos que quedarían Bloqueado |
|---|---|
| Versión de ensayo con HU-002 | Todos |
| Cuenta inactiva preparada (PA-03) | ACC-ING-006 |
| Función restringida conocida (PA-04) | ACC-ING-010 |
| Lectura de base y registros (PA-05) | ACC-ING-009 |
| Cerrar sesión disponible | ACC-ING-007 |
