# 1.1 Análisis de la historia HU-005

**Fase:** Preparación
[Volver al flujo](../00_Flujo_metodologico.md)

## Ficha de la historia

| Elemento | Contenido |
|---|---|
| Historia | Como persona autenticada, quiero cerrar mi sesión, para terminar mi acceso a las funciones que requieren identificación. |
| Actor | Persona autenticada |
| Objetivo | Finalizar la sesión actual y retirar acceso a funciones protegidas hasta nuevo ingreso válido. |
| Requisito / prioridad | RF-005 · Alta |
| Reglas de negocio | No tiene una regla de negocio específica. |
| Dependencias | HU-002, HU-008, RNF-002 |
| Condiciones de calidad | RNF-002, RNF-004, RNF-005 |
| Resultado esperado | Sesión finalizada y acceso protegido retirado hasta un nuevo ingreso válido. |

## Precondiciones y flujo

1. Existe una sesión iniciada.
2. La persona dispone de la acción Cerrar sesión.
3. Seleccionar Cerrar sesión; el sistema finaliza la sesión; deja de tratar a la persona como autenticada; al solicitar una pantalla protegida pide nuevo ingreso.

## Reglas y dependencias

El cierre no elimina cuenta ni historial. Una dirección protegida no recupera por sí sola la sesión finalizada. Cerrar sesión no desactiva la cuenta. HU-002 (Grupo 1) aporta ingreso; HU-004 (Grupo 1) proporciona Perfil como pantalla protegida de referencia; HU-008 (otro grupo) se cita solo como dependencia, sin diseñar sus casos.

## Elementos verificables

| Elemento | Origen |
|---|---|
| Seleccionar Cerrar sesión finaliza la sesión | CA-HU-005-01 |
| Pantalla protegida no muestra contenido y solicita ingreso | CA-HU-005-02 / RNF-002 |
| Atrás y abrir dirección desde historial/pegar no recuperan acceso | CA-HU-005-03 |
| Acceso se determina por nueva sesión; misma cuenta u otra | CA-HU-005-04 |
| Uso con teclado y desde computador/teléfono | RNF-004 / RNF-005 |
| Cuenta e historial permanecen, no se desactiva cuenta | Restricciones |
