# 4.1 Gestión de incidencias · HU-005

**Fase:** Evaluación · [Volver al flujo](../00_Flujo_metodologico.md)

Sin corrida registrada; no hay incidencias. Procedimiento: reproducir diferencia observada; anotar ambiente, versión, dato y caso/script/paso; trazar a criterio/RNF; acordar severidad y prioridad; asignar a desarrollo; tras corrección ejecutar una nueva corrida y registrar verificación.

| Campo del reporte | Contenido |
|---|---|
| ID | INC-ACC-CIE-NNN |
| Corrida / versión | C-___ / ___ |
| Caso / script / paso | ACC-CIE-___ / SCR-ACC-CIE-___ / ___ |
| Criterio o RNF | CA-HU-005-__ / RNF permitido |
| Esperado / real | Copias y observación literal |
| Evidencia | Se agrega durante ejecución |
| Estado | Nuevo |

Ciclo: Nuevo → Abierto → Asignado → Corregido → Verificado → Cerrado; también Rechazado, Diferido o Reabierto.
