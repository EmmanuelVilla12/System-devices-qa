# 1.3 Tipos y técnicas de prueba · HU-009

## Objetivo

Definir los tipos y técnicas que se utilizarán para diseñar las pruebas de la historia HU-009.

## Tipos de prueba

| Tipo | Aplicación en HU-009 |
|---|---|
| Funcional | Verificar que las direcciones inexistentes muestren el mensaje correspondiente. |
| No funcional | Comprobar que el mensaje sea comprensible y legible en diferentes dispositivos. |
| Regresión | Comprobar que las restricciones de acceso de pantallas existentes sigan diferenciándose de una página inexistente. |

## Técnicas de prueba

| Técnica | Aplicación |
|---|---|
| Caja negra | Evaluar las respuestas del sistema a partir de las direcciones solicitadas y el tipo de usuario. |
| Partición de equivalencia | Separar direcciones existentes, inexistentes y existentes con acceso restringido. |
| Tabla de decisión | Relacionar el estado de la dirección y la condición de autenticación con la respuesta esperada. |
| Pruebas de interfaz | Revisar que el mensaje sea visible, comprensible y legible. |

## Condiciones que se deben diferenciar

1. Dirección inexistente solicitada por un visitante.
2. Dirección inexistente solicitada por una persona autenticada.
3. Pantalla existente protegida solicitada por un visitante.
4. Pantalla existente protegida solicitada por una persona autenticada sin permisos.

## Relación con criterios y RNF

- CA-HU-009-01: prueba funcional de dirección inexistente.
- CA-HU-009-02: prueba funcional para diferentes estados de autenticación.
- CA-HU-009-03: prueba de diferenciación entre página inexistente y acceso restringido.
- CA-HU-009-04: verificación de ausencia de cambios en registros.
- RNF-004: revisión de comprensión del mensaje.
- RNF-005: revisión de legibilidad en computador y dispositivos móviles.

## Consideraciones

- Las pruebas serán diseñadas para ejecución manual.
- No se asignarán códigos de estado HTTP ni rutas reales que no estén especificadas en la historia.
- Las pruebas de acceso restringido dependen del comportamiento definido en HU-008.
- No se registrarán resultados hasta realizar una ejecución real.
