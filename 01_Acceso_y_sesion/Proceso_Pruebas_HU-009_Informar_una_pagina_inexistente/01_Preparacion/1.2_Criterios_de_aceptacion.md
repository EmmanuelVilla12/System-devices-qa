# 1.2 Criterios de aceptación · HU-009

## Objetivo

Identificar los criterios que deben cumplirse para considerar correcta la funcionalidad de informar una página inexistente.

## Criterios de aceptación

| Identificador | Criterio | Resultado esperado |
|---|---|---|
| CA-HU-009-01 | Cuando se solicita una dirección que no corresponde a una pantalla existente, el sistema debe informar «Página no encontrada». | Se presenta el mensaje y no aparece una pantalla en blanco. |
| CA-HU-009-02 | La respuesta debe funcionar para visitantes y personas autenticadas. | Ambos tipos de usuario reciben una explicación al solicitar una dirección inexistente. |
| CA-HU-009-03 | Cuando se solicita una pantalla existente con restricciones, el sistema debe aplicar las reglas de acceso de HU-008. | Se solicita iniciar sesión o se muestra «Acceso denegado», según corresponda; no se informa una página inexistente. |
| CA-HU-009-04 | La consulta de una dirección inexistente no debe crear ni modificar registros. | No se producen cambios en registros de usuarios, equipos o préstamos. |

## Relación con requisitos no funcionales

| Identificador | Requisito | Verificación |
|---|---|---|
| RNF-004 | Mensaje identificable y comprensible. | Revisar que el mensaje permita reconocer que la página no existe. |
| RNF-005 | Legibilidad en computador y dispositivos móviles. | Comprobar que el texto sea visible y no quede cortado. |

## Reglas de validación

- Cada criterio debe tener al menos un escenario de prueba.
- Los resultados deben ser observables y verificables.
- No se deben agregar condiciones que no estén definidas en la historia de usuario.
- Los criterios relacionados con permisos deben respetar la dependencia de HU-008.
