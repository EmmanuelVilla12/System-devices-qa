# Flujo metodológico · HU-009

## Objetivo

Establecer el proceso de trabajo para diseñar y documentar las pruebas de la historia de usuario HU-009.

## Etapas del proceso

| Etapa | Actividad | Resultado |
|---|---|---|
| 1. Preparación | Analizar la HU, sus criterios y restricciones. | Requisitos identificados. |
| 2. Diseño | Definir escenarios y técnicas de prueba. | Escenarios documentados. |
| 3. Implementación | Crear plan, matriz, datos, casos y scripts. | Documentos de prueba elaborados. |
| 4. Revisión | Revisar consistencia y trazabilidad entre documentos. | Documentación lista para revisión por pares. |
| 5. Ejecución | Ejecutar los casos cuando exista un ambiente disponible. | Registro de resultados y evidencias. |
| 6. Evaluación | Analizar resultados e incidencias. | Informe y oportunidades de mejora. |

## Reglas de trabajo

- Cada criterio de aceptación debe estar relacionado con al menos un escenario.
- Cada escenario debe tener al menos un caso de prueba.
- Cada caso debe tener un script asociado.
- Los datos de prueba deben estar identificados y documentados.
- No se deben inventar comportamientos que no estén definidos en la HU.
- Las dudas sobre requisitos se registran como preguntas abiertas.
- No se deben registrar resultados ni evidencias de pruebas que no se hayan ejecutado.

## Estado del proceso

La documentación se encuentra en etapa de diseño y está pendiente de revisión por pares. La ejecución y evaluación permanecen sin iniciar.
