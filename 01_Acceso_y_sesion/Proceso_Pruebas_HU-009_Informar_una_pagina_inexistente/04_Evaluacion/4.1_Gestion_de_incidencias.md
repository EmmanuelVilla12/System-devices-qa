# 4.1 · Gestión de incidencias HU-009

**Historia de usuario:** HU-009 · Informar una página inexistente  
**Estado:** Sin incidencias registradas

## 1. Objetivo

Definir cómo se registrarán y gestionarán las incidencias que puedan aparecer durante la ejecución de las pruebas.

## 2. Registro de incidencias

| ID | Caso asociado | Descripción | Prioridad | Estado |
|---|---|---|---|---|
| Sin registros | No aplica | No se han reportado incidencias porque las pruebas no se han ejecutado. | No aplica | Sin registrar |

## 3. Proceso de gestión

1. Identificar el comportamiento que no cumple el resultado esperado.
2. Registrar el caso de prueba relacionado.
3. Describir los pasos para reproducir el problema.
4. Adjuntar la evidencia disponible.
5. Asignar una prioridad según el impacto.
6. Dar seguimiento hasta su solución y verificación.

## 4. Información requerida

Cada incidencia deberá incluir:

- Identificador con nomenclatura INC-ACC-PNE-NNN.
- Caso de prueba relacionado.
- Descripción del problema.
- Pasos para reproducirlo.
- Resultado esperado y resultado obtenido.
- Evidencia.
- Prioridad y estado.

## 5. Estado actual

No existen incidencias registradas. Las pruebas de HU-009 permanecen sin ejecutar.
