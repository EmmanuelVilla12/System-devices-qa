# 2.6 · Ambiente de pruebas HU-009

**Historia de usuario:** HU-009 · Informar una página inexistente  
**Estado:** Borrador para revisión por pares  
**Ejecución:** No ejecutado

## 1. Objetivo

Definir las condiciones y recursos necesarios para realizar las pruebas de la página inexistente.

## 2. Recursos necesarios

| Recurso | Descripción |
|---|---|
| Aplicación | Versión de pruebas del sistema. |
| Navegador | Navegador web actualizado. |
| Computador | Equipo para pruebas de escritorio. |
| Dispositivo móvil | Dispositivo o herramienta de visualización adaptable. |
| Usuarios de prueba | Cuentas autorizadas para validar los diferentes niveles de acceso. |
| Base de datos | Acceso de consulta autorizado para verificar que no se modifiquen registros. |

## 3. Configuración de visualización

| Dispositivo | Resolución de referencia |
|---|---|
| Computador | 1366x768 |
| Móvil | 390x844 |

## 4. Condiciones del ambiente

- La aplicación debe estar disponible en un entorno autorizado de pruebas.
- Las cuentas utilizadas deben ser ficticias y estar habilitadas para las verificaciones.
- Las rutas protegidas deben ser confirmadas por el equipo responsable.
- La dirección ficticia de prueba debe comprobarse como inexistente.
- No se deben realizar pruebas sobre información de producción.

## 5. Consideraciones

La disponibilidad de la aplicación, las rutas protegidas y los permisos de las cuentas deben confirmarse antes de ejecutar los casos.
